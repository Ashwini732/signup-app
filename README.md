
# Sign Up and Login App

A user authentication application built using React, Express.js, REST API, and MongoDB.

## Features
- User registration
- User login
- Password hashing using bcryptjs
- MongoDB database integration
- Form validation

## Technologies Used
- React
- Node.js
- Express.js
- MongoDB
- Mongoose
- bcryptjs

## Project Structure
- `client/` - React frontend
- `server/` - Express backend and MongoDB integration

## How to Run

### Backend
1. Open the `server` folder.
2. Install dependencies using `npm install`.
3. Create a `.env` file with your MongoDB connection string.
4. Start the server using `node server.js`.

### Frontend
1. Open the `client` folder in another terminal.
2. Install dependencies using `npm install`.
3. Start the frontend using `npm start` or `npm run dev`, depending on the scripts in `client/package.json`.
